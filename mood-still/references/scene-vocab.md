# 意境 → 画面检索表

供 agent 查阅，**不做机器校验**。它是"从意境到参数"的检索起点，不是模板池——可以越表取值。

## 情绪 → 身体与站位

| 情绪 | 动作要点（写进 `scene.action`） | 景别 | 光 |
|---|---|---|---|
| 关切 | 一方前倾、头微偏、视线锁住对方 | 中近景双人 | 暖光在关切者背后 |
| 隐瞒 | 手背到身后、肩内收、视线向下 | 近景，被瞒方在前景 | 主体半侧入影 |
| 羞愧 | 低头、缩肩、身体侧转避开视线 | 特写或近景 | 顶光偏冷 |
| 试探 | 一方半转身、回头一看、耳朵/眉毛先动 | 中景留白多 | 侧逆光 |
| 赌气 | 背对、双手抱胸、距离拉远 | 全景，两人分居两侧 | 平光、无暖色 |
| 告别 | 一人已走一人留在原地、间距最大 | 远景 | 低角度暖光 |
| 重逢 | 距离正在缩短、身体朝向彼此 | 中景 | 逆光带雾 |
| 沉默 | **说话人不在画面焦点，倾听方在前景** | 近景，聚焦倾听方 | 单一光源 |
| 雀跃 | 重心前移、耳朵/头部上扬、尾巴高卷 | 中景带环境 | 高亮暖调 |

## 时段 → 色温

| time | 天空 | 主光 | 氛围 |
|---|---|---|---|
| 清晨 | 淡蓝灰 | 低角度侧光 | 干净、克制 |
| 正午 | 亮白 | 顶平光 | 直白、无隐瞒 |
| 傍晚 | 蓝紫转暖 | 单一路灯/窗光 | 柔软、迟疑 |
| 夜 | 深蓝 | 人工点光源 | 孤独或亲密 |
| 雨后 | 灰白透光 | 漫射 | 释然 |

## 天气 → 情绪加成

- 小雨：放大"等待"与"没准备好"（忘带伞、没接话）
- 大雨：把两人逼进同一处屋檐，强制靠近
- 阴：削掉戏剧性，适合平淡的坦白
- 起雾：让远处的东西看不见，适合隐瞒
- 雪：安静、时间变慢，适合告别

## 场景三元组要换

`drift_check` 把 `place + time + weather` 当**一个维度**。三张候选若都用"屋檐下 / 傍晚 / 小雨"，这一维就整批丢掉。同一幕戏换到"玄关 / 清晨 / 阴"是完全合法的读法，而且往往更能说明 agent 真的理解了意境而不是在复述字面。
