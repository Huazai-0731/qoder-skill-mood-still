# 固定测试语料

`drift_check.py` 与人工终审都用这几段。每段附"至少可成立的选句集"，用来比对 agent 挑得准不准。

## T1 · 明知故问

```
柴犬：你带伞了吗？
小男孩：……没有。
柴犬：我闻到了。
```

**考点**：转折在第 2 句（承认），但最强的画面在第 3 句（被揭穿）。
可成立选句：2、3。不可成立：1（只是提问，关系还没动）。

## T2 · 只有倾听方能演

```
小男孩：对不起，我把你送我的东西弄丢了。
柴犬：…………
小男孩：你骂我一句吧。
柴犬：回家吃饭。
```

**考点**：沉默（第 2 行）没有任何台词内容可画，只能靠**倾听方的身体**演出。这是最能区分"懂意境"与"读字面"的一段。
可成立选句：2（沉默）、4（用日常话盖过情绪）。

## T3 · 环境藏在潜台词里

```
柴犬：你又忘带伞了。
小男孩：这次是真的忘了。
柴犬：上次你也这么说。
```

**考点**：字面没有"雨"，但"又"和"上次"暗示这是重复发生的、且外面正在下雨。画面里必须有雨，而雨不能来自字面。
可成立选句：1、3。检查点：生成的 `scene.weather` 是否为雨。

## T4 · 单人反应（边界用例）

```
柴犬：他们说明天就把我送去乡下。
```

**考点**：只有一行、只有一个说话人。一期舞台允许 1 个角色，但**没有"关系位移的对象"**——agent 应当仍能落成画面（独处、被留下的姿态），或明确回答"这一幕的关系不在台词里，我表达不了"。两种回答都算通过，硬凑一张无关的风景算失败。

## T5 · 无处落笔（拒绝分支，US-7）

```
柴犬：明天六点出发。
小男孩：几点回来？
柴犬：四点。
小男孩：好。
```

**考点**：名字合法、人数合法、行数合法，但**四行全是信息往来，没有一句让关系发生位移**——`line_pick` 维度是空的，场景的六个字段也就没有依据可填。与 T4 不同，这里**唯一正确的回答是拒绝**："表达不了 + 缺哪个维度"（缺的是**选句**），并给出重读的路径；硬凑一张"出发前夜/两人在家"的日常图 = 失败——画面与台词的唯一关系是编造。可成立选句：**无**（这正是考点）。

**边界**（防过度拒绝）：任何一句被读出姿态，这里就该照常出候选，例如末行改成「……好。」（停顿）或「你定吧。」（退让）。拒绝与否的边界在"关系动没动"，不在"句子平不平"。判例：2026-09-30 首次真实触发，拒绝回复逐字留档在开发仓库的 `work/us7-demo/`（那份留档**不随 skill 分发**，本文件才是可执行的用例）。
