# mood-still（意境定格）

把一段**多轮对白**演成一张动漫画风的**静态定格插画**。

它演的是"关系发生位移"的那一刻——靠近、退开、隐瞒、被揭穿、欲言又止——不是给台词配一张好看的图。一次给 2-3 张不同选句的候选，落进本地画廊，由人挑保留张。

一期只交静态 PNG。不做动画、不做骨骼绑定、不做脱离对白的随机配图。

## 安装

需要 Qoder（或兼容的 skill 加载器）。**skill 所在目录必须叫 `mood-still`**（结构自检会查这一条）：

```bash
git clone git@github.com:Huazai-0731/qoder-skill-mood-still.git /tmp/qsm
cp -r /tmp/qsm/mood-still ~/.qoder-cn/skills/mood-still     # 用户级：全部项目可用
# 或放进单个项目的 .qoder/skills/mood-still
```

前置条件：本机需有 `node`（跑拼装器与闸门，零 npm 依赖）与 Python + Pillow（叠气泡）。中文字体路径写在 `mood-still/assets/bubble.json`（含两条回退），三处都没有时脚本会明确报 `no CJK font found`，不会画出一张空气泡。

装好后自检一下：

```bash
node ~/.qoder-cn/skills/mood-still/scripts/check_skill.cjs      # 结构与引用
node ~/.qoder-cn/skills/mood-still/scripts/mutation_test.cjs    # 26 例变异实验
```

## 怎么用

在任意项目里贴对白，说一句"把这一幕画出来"。对白格式必须是行首 `角色名：台词`。

```
柴犬：你带伞了吗？
小男孩：……没有。
柴犬：我闻到了。
```

台上目前只有两个角色：**柴犬**、**小男孩**。名字写错它会停下来列出可用角色，不替你猜；一场最多 2 个角色，超过直说不支持。台词里提到第三人可以，但开口的只能有 2 个。

## 你会拿到什么

产物落在**当前项目根目录**的 `gallery/`，每次一组：

```
gallery/groups/2026-10-01-01/
  _scenes.json     这一组的输入（对白 + 每张候选选哪句、场景、气泡）——要改就改它
  prompt-1.txt     实际送进图像模型的完整提示词（可审计）
  base-1.png       没叠字的底图
  frame-1.json     帧规格（选句声明、站位、气泡锚点、digest）
  frame-1.png      ★ 成品：底图 + 中文气泡
  kept.json        你签字保留的那张（或几张）
gallery/index.html 双击即开，按对白分组，保留张带橙框高亮
```

**你只需要看 `gallery/index.html`**，其余是复核用的证据。

## 你要做的三件事

1. **挑保留张**——看一眼画廊，说"保留第二张"。
2. **说清哪里不对**——选错句子 / 表情不对 / 构图太挤 / 不像同一只。改的是 `_scenes.json` 再重跑，不会偷偷改成品。
3. **别拿机器绿当通过**——所有闸门查的都是文本字段与几何，**画面里角色在笑还是在哭，机器一概不知**。最后一眼永远是你的。

## 遇到这些情况怎么办

| 现象 | 是什么意思 | 你能怎么办 |
|---|---|---|
| 它回答"**表达不了**"并指出缺哪个维度 | 这段对白没有一句让关系动一下，硬画只能得到一张与台词无关的图 | 补一句有姿态的台词；或告它某句该往哪个方向读（"那句『好。』其实是松了口气"） |
| 低沉的句子里角色在**笑** | 模型对"柴犬+anime+正脸坐着"的先验就是笑脸，写"不要笑"基本无效 | 要求换**姿态**（趴下、下巴压爪、头低垂）——实测最有效的杠杆 |
| 气泡里的字比原句短 | 超容量时按标点压缩，`original` 保留原句，画廊里两者不一致会高亮 | 不接受就说"用原句"，它会换选句或换景别 |
| 引线的泡泡指错人 | 锚点估偏了 | 跑 `scripts/anchor_grid.py` 把网格与头部圆叠到底图上，读数改准再重出 |
| 画面里混进文字、招牌、乱码 | 违反硬禁令，这张作废 | 看图自查本该拦住；漏了你直接说 |
| 右下角"Qoder AI 生成" | 出图管线的固定水印，每张都有 | 忽略，不是废图理由 |
| 同一候选反复不对 | 重出上限 2 次 | 到顶它会如实说"这一句我拿不到对的表情"，而不是交一张错的 |

## 成本与节奏

一张图一次调用，**没有局部重画**——构图不满意只能整张重出。一次最多 3 张候选，且三张必须选不同的句子或场景，否则被死板闸拦下。想换读法直说："三张太像了，换一种场景"——同一幕戏搬到"玄关 / 清晨 / 阴"是完全合法的。

## 明确不做

动画片段、GIF、骨骼与关节、>2 角色同框、小猫或火柴人角色、由图像模型生成中文、自动挑最佳候选。这些是设计上的边界，不是待修 bug。

## 仓库结构

```
mood-still/                 ← skill 本体，整目录拷进 skills 目录即可
  SKILL.md                  给 agent 的工作流与闸门（不是给人看的说明书）
  assets/                   设定卡 roster.json、画风锁 style-lock.txt、气泡样式 bubble.json
  references/               帧规格、气泡口径、场景检索表、测试语料 T1-T5、闸门夹具
  scripts/                  拼装、合成、五道自检
README.md                   本文件
```

三条内部约定，改代码前值得知道：

- **设定卡与画风锁逐字复用**，`validate_frame.cjs` 的 D4 做逐字节比对——所以本仓库用 `.gitattributes` 钉死 LF 行尾，否则换机器 clone 会报"素材漂移"的假报警。
- **气泡容量只由 `compose_bubble.py` 的 `wrap()` 判定**，别在任何地方复算列数（实测两串同为 19 列，`……答案！！` 画得下、`……答案（（` 画不下）。
- **头部圆盘几何只在 `compose_bubble.head_disc()` 定义一处**，`anchor_grid.py` import 它，两边永远是同一个圆。

## 维护

改了 `assets/`、`scripts/` 或 `SKILL.md`，跑 `node mood-still/scripts/mutation_test.cjs`（26 例）——它证明闸门真的会咬，而不只是证明代码能跑。新增角色只改 `assets/roster.json` 的设定卡，不动脚本；设定卡**只写不变的外观**，情绪一律由场景段承担（写进卡里会把表情焊死在每一张图上）。
